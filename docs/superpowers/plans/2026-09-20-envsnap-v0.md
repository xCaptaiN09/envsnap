# EnvSnap V0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build envsnap V0 CLI with save/open working end-to-end via TDD.

**Architecture:** Click+Rich CLI calls detector modules returning dicts, packer writes .envsnap tar.gz, opener verifies+restores.

**Tech Stack:** Python 3.10+, Click, Rich, pytest, typesafe-sdk==0.7.0

**Spec:** docs/superpowers/specs/2026-09-20-envsnap-design.md

## Global Constraints
- Commands are exactly save/open/share + bare menu.
- Never store secret values, only KEY=<ask> template.
- Skip node_modules, venv, .git, __pycache__ always.
- pytest -q must pass before any completion claim.
- PYTHONPATH=src for all pytest runs; pytest>=7.
- TypeSafe thresholds (code-enforced): secret Noul >=0.7 block, risk Score dangerous=>no auto-run, needs-check=>confirm.
- V0 share = local file path print + direct LAN stub message; relay = V0.2 (explicit, no silent missing).
