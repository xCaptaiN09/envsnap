**Goal:** Interactive save/open wizards + real restore + easy install.

**Architecture:** Click prompts drive save/open; setupgen writes setup.sh from manifest; restore extracts code.tar.gz fully.

**Tech Stack:** Python 3.10+, Click, Rich, pytest
